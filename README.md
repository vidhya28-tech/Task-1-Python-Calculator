# Python CLI Calculator

## Task 1 – Build a Calculator CLI App

A simple command-line calculator developed using Python. The application performs basic arithmetic operations and continues running until the user chooses to exit.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Continuous menu-driven interaction
- Input validation
- Division-by-zero handling
- Separate functions for each operation

## Technologies Used

- Python
- VS Code
- Terminal

## Project Structure

ElevateLabs_Python_Task1/

└── README.md

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

python calculator.py

4. Select an operation from the menu.
5. Enter the required numbers.
6. Select option 5 to exit.
